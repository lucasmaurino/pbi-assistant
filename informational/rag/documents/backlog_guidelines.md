# Backlog Management Guidelines

All Product Backlog Items (PBIs) must follow standardized lifecycle states:

- To Do: Work has not yet started
- In Progress: Actively being developed
- Done: Fully implemented, tested, and validated

A PBI can be moved to Done only when:

- All acceptance criteria are met
- Code has been reviewed and approved
- Automated tests are passing
- Documentation is updated if required

PBIs should always be associated with a Feature to ensure alignment with business objectives.

Assignments should reflect clear ownership to promote accountability and efficient delivery.
